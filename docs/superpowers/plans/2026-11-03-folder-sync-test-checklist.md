# 폴더 동기화 수동 테스트 목록

브랜치: `feat/folder-sync`. 실제 Seafile 계정으로 로그인한 데스크톱 앱(`npm run tauri dev`)에서 확인한다.

1. **연결 추가**
   - [동기화 폴더 추가]로 테스트 폴더를 연결한다.
   - 확인 창에 크기, 파일 수, 남은 용량이 나오는지 본다.
   - 드라이브에 같은 이름의 폴더가 생기고 파일이 올라가는지 본다.
2. **저장·삭제 반영**
   - PC 폴더에 파일을 저장하면 몇 초 안에 드라이브에 보이는지 본다.
   - PC에서 지우면 드라이브에서도 지워지는지 본다.
3. **대량 삭제 확인**
   - 파일 10개를 동기화한 뒤 PC에서 전부 지운다.
   - 확인 창이 뜨는지 본다.
   - [취소]하면 드라이브에 파일이 그대로 남는지 본다.
4. **PC 폴더가 사라졌을 때**
   - PC 폴더 이름을 바꾼다.
   - 드라이브는 그대로이고 "PC 폴더를 찾을 수 없음"이 표시되는지 본다.
   - 이름을 되돌리면 1분 안에 다시 이어지는지 본다.
5. **Word 저장**
   - 동기화 폴더의 `.docx`를 Word로 고쳐 저장한다.
   - `~$` 임시 파일은 올라가지 않는지 본다.
   - 원본만 갱신되는지 본다. 드라이브 파일 히스토리에 새 버전이 생겨야 한다.
6. **창 없이 자동 실행** ⚠️ 가장 확인이 안 된 부분
   - 로그인할 때 "자동 로그인"을 체크한다.
   - 연결해 둔 상태로 앱을 끈다.
   - PC 폴더에 파일을 추가한다.
   - `npm run tauri dev -- -- --autostart`로 창 없이 켠다.
   - 몇 초 안에 드라이브에 올라가는지 본다.
7. **읽기 전용과 관리 메뉴**
   - 동기화 폴더 안에서 업로드, 끌어다 놓기, 새 폴더, 이름 변경, 삭제, 끌어서 옮기기가 꺼져 있는지 본다. 상태 표시줄에 "동기화 폴더 · 읽기 전용"이 보이는지 본다.
   - 밖의 파일을 동기화 폴더로 끌어 옮기면 막히는지 본다.
   - PC에서 파일을 지우면 새로고침 없이 드라이브 목록에서도 사라지는지 본다.
   - 동기화 폴더를 우클릭해 일시정지, 다시 시작, 지금 동기화, PC 폴더 열기, 동기화 해제를 차례로 해 본다.

## 알려진 한계

- Windows에서 동기화 중인 폴더의 **상위 폴더**를 탐색기에서 이름을 바꾸거나 지우지 못할 수 있다(변경 감시가 폴더를 잡고 있음, 재현 안 해 봄).
- PC에서 파일이 여러 번에 나뉘어 사라지면 매번 기준보다 적어서 확인 없이 지워진다.
- 파일 수만 개를 처음 올릴 때 파일 하나가 끝날 때마다 화면이 한 번씩 다시 그려진다.
