# 디자인나스 수동 테스트 목록

브랜치: `docs/nas-browse`. PC 두 대로 확인한다. 제공 PC는 하드가 붙은 Seafile 서버 PC(디자인나스로 로그인), 받는 PC는 같은 사무실 네트워크의 디자이너 PC다. 둘 다 `npm run tauri dev` 또는 설치본으로 연다.

1. **NAS로 열기 (제공 PC)**
   - 설정 → NAS에서 [NAS로 열기]로 테스트 폴더(또는 하드)를 고른다.
   - 확인 창에 크기와 파일 수를 세지 않고 바로 뜨는지 본다.
   - 연 뒤 "검색 색인 N개 만드는 중…"이 올라가다가 끝나는지 본다.
2. **방화벽 허용**
   - 처음 열 때 Windows 방화벽 창이 뜨면 "개인 네트워크"를 허용한다.
   - 허용하지 않으면 받는 PC에서 보이지 않는지, 허용한 뒤 보이는지 본다.
3. **사이드바 표시 (받는 PC)**
   - 사이드바 "NAS"에 제공 PC 로그인 계정 이름(예: 디자인나스)이 뜨는지 본다.
   - 라이브러리 이름 옆에 읽기 전용 표시가 있는지 본다.
4. **폴더 탐색**
   - 폴더를 여러 단계 들어가고 되돌아 나오는지 본다.
   - 한글 이름, 공백이 든 이름, 아주 긴 이름의 폴더를 열어 본다.
   - 미리보기, 썸네일, 공유, 바로 보내기, 즐겨찾기, 이름 변경, 삭제, 업로드, 끌어다 놓기가 보이지 않는지 본다.
5. **검색**
   - 색인이 끝나기 전에는 검색이 안 되고, 끝난 뒤에는 이름으로 찾아지는지 본다.
   - 제공 PC에서 파일을 추가하거나 지운 뒤 검색 결과에 반영되는지 본다.
6. **큰 파일 내려받기**
   - 1GB 이상 파일을 내려받는다. 다운로드 패널에 진행률이 나오고 내용이 원본과 같은지 본다(해시 비교).
   - 받는 도중 제공 PC의 앱을 끄면 실패로 표시되는지 본다.
7. **제공 쪽 앱을 끄면 사라짐**
   - 제공 PC에서 [닫기]를 누르면 받는 PC 사이드바에서 몇 초~5분 안에 사라지는지 본다.
   - 로그아웃해도 같은 결과인지 본다.
   - 다시 로그인하면 폴더를 다시 고르지 않아도 자동으로 열리고, 받는 PC에 다시 뜨는지 본다.
8. **다른 서버 계정에는 안 보임**
   - 받는 PC를 다른 Seafile 서버 주소로 로그인하면 사이드바에 나타나지 않는지 본다.
9. **서버 PC 재부팅**
   - 제공 PC를 다시 켠다. 자동 실행과 자동 로그인 뒤 사람이 손대지 않아도 NAS가 다시 열리는지 본다.
   - 받는 PC 사이드바에 다시 뜨는지 본다.
10. **경로 제한**
    - 제공 폴더 안에 `mklink /J`로 폴더 밖을 가리키는 정션을 만든다.
    - 받는 PC에서 그 정션을 열면 실패하는지 본다.

## 알려진 한계

- 사무실 네트워크에서 Drive 앱을 쓰는 사람이면 누구나 읽을 수 있다(인증을 두지 않기로 한 결정).
- 제공 PC의 사이드바에도 자기 NAS가 같이 보인다.
- 정션으로 폴더 밖을 빠져나가는 것을 막는 검사는 Unix에서만 단위 테스트로 확인했다. Windows는 `canonicalize`에 기대므로 10번을 직접 해 본다.
- 하드가 크면 처음 연 뒤 검색 색인을 만드는 데 시간이 걸린다. 그동안 탐색과 내려받기는 되지만 검색은 되지 않는다.
